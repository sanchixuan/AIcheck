# AIcheck

Fork 维护者：喵喵轩。上游项目：[alwayslone/AIcheck](https://github.com/alwayslone/AIcheck)。

一个使用root权限运行的快捷作业检查软件

通过截图发给ai，再将ai返回的结果显示出来

音量上控制悬浮窗显示,音量下控制截图发给ai

需要复制时，在应用首页点击「复制最近结果」。停止服务后会清除应用内暂存的结果。

在首页的「API 配置」里可以添加并保存多套配置。每套配置需要名称、支持图片输入的 Chat Completions 完整 HTTPS 地址、API Key 和模型，也可以填写专用提示词。选中某套配置后，后续请求会使用该配置。
